# SoK: Generative AI in Assessment — Engineering, STEM & CS Education

Systematization of Knowledge (SoK) review repository.  
**Venue:** IEEE TALE 2026 — Assessment Revolution track.

> Lau, S. L. (2026). *Generative AI in Assessment within Engineering, STEM, and Computing Education: A Systematization of Knowledge.* Proceedings of IEEE TALE 2026.

This repository contains the **input data and analysis code** needed to reproduce the findings reported in the paper. PDF retrieval is not included; obtain papers via your institutional subscriptions using DOIs in `data/processed/corpus_final.json`.

---

## What's included

| Path | Contents |
|---|---|
| `data/raw/` | Original BibTeX exports from all 5 databases |
| `data/processed/corpus_final.json` | 641-paper final corpus (title, authors, year, DOI, filename) |
| `data/processed/affiliations_enriched.csv` | OpenAlex-enriched author affiliations for IEEE/ACM/ERIC records |
| `analysis/bibliometrics/` | R + Python scripts for bibliometric analysis |
| `analysis/content_analysis/` | Dual-round taxonomy coding scripts |
| `analysis/outputs/` | Generated figures and tables (populated after running) |

**Not included:** `_pdfs/` (~3 GB, 617 files) — retrieve using DOIs in `corpus_final.json`.

## Reproducing the Analysis

### Prerequisites

```bash
# Python
pip install pymupdf pypdf pandas tqdm requests bibtexparser

# R
Rscript -e 'install.packages(c("bibliometrix", "tidyverse", "here"))'
```

Place the 641 PDFs in `_pdfs/` (filenames match `corpus_final.json → filename` field).

### Step 1 — Bibliometric analysis

```bash
# Normalise IEEE/ACM/ERIC BibTeX to Scopus-compatible format
python3 analysis/bibliometrics/00_normalize_bib.py
# → data/raw/ieee_acm_eric_normalized.bib

# Load all 5 databases, merge and deduplicate (2,122 records)
Rscript analysis/bibliometrics/01_load_and_merge.R
# → data/processed/bibliometrix_merged.rds

# Export for affiliation enrichment
Rscript -e 'write.csv(readRDS("data/processed/bibliometrix_merged.rds"),
            "data/processed/bibliometrix_merged.csv", row.names=FALSE)'

# Enrich author affiliations via OpenAlex API (resumable — safe to interrupt)
python3 analysis/bibliometrics/01b_enrich_affiliations.py
# → data/processed/affiliations_enriched.csv

# Apply enriched affiliations
Rscript analysis/bibliometrics/01c_apply_affiliations.R

# Generate all figures and tables
Rscript analysis/bibliometrics/02_bibliometric_analysis.R
# → analysis/outputs/figures/*.png
# → analysis/outputs/tables/*.csv
```

### Step 2 — Dual-round taxonomy coding

Two independent rounds code the same 617-paper corpus. Only papers assigned by **both** rounds are counted in the paper (consensus rule).

| | Round 1 | Round 2 |
|---|---|---|
| PDF library | PyMuPDF (`fitz`) | `pypdf` |
| Pages read | All | All |
| Vocabulary | Set A — primary terms | Set B — synonyms/paraphrases |
| Match rule | Any 1 keyword | ≥ 2 distinct keywords |
| Default | Category G | None (unmatched = uncoded) |

```bash
# Round 1
python3 analysis/content_analysis/01_text_extraction.py
python3 analysis/content_analysis/02_thematic_coding.py

# Round 2
python3 analysis/content_analysis/01b_text_extraction_alt.py
python3 analysis/content_analysis/02b_thematic_coding_alt.py

# Consensus (reported counts + per-category agreement rates)
python3 analysis/content_analysis/03_consensus.py
# → analysis/outputs/tables/consensus_summary.txt
# → analysis/outputs/tables/taxonomy_consensus.csv
# → analysis/outputs/tables/taxonomy_disagreements.csv
```

## Seven-Category Taxonomy

| Cat. | Theme | Evidence quality |
|---|---|---|
| A | Automated Grading | Moderate — small-n empirical, limited validity |
| B | Authentic Assessment Redesign | Low — conceptual/framework, few evaluations |
| C | Academic Integrity | Moderate — detection studies; policy surveys |
| D | Formative and Adaptive Assessment | Moderate–High — controlled studies in ITS/CS1 |
| E | Ethics and Policy | Low — framework/opinion; sparse empirical |
| F | Perception and Affect | Moderate — survey-heavy, cross-sectional |
| G | Review / Methodology | N/A — methodological metadata dimension |

All counts are **consensus-only** (both rounds agree). Category G is a methodological metadata dimension, not a substantive thematic category on the same level as A–F.

## Key Findings

- **Growth**: CAGR 204% (2023–2025); ~9× growth from 114 papers (2023) to 1,054 papers (2025)
- **Venues**: 777 unique sources; ASEE, ACM SIGCSE, FIE dominant
- **Geography**: US (18.8%), China (15.2%), India (5.0%); 9.9% international co-authorship
- **Keyword clusters**: Disciplinary Contexts, GenAI/Assessment Discourse, LLM Applications, CS/Computing Pedagogy
- **Structural gap**: <10% of empirical papers report a controlled evaluation of an implemented intervention
